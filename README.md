# Threads 名單封鎖工具

這是一個 Chrome 擴充功能，幫你整理 Threads 某篇貼文或某則留言的按讚帳號，讓你確認名單後一次開始封鎖，不必自己逐人開主頁操作。

## 可以做什麼？

- 收集你在 Threads 網頁上能看到的按讚帳號。
- 勾選要封鎖的人，也可以選擇加入這則內容的作者；自動排除自己。
- 確認名單後，在背景處理封鎖，並顯示成功、待檢查與取消的結果。
- 隨時暫停或中止，匯出名單與操作紀錄。
- 漏勾必要確認時，直接標示要勾選的位置。

## 安裝

1. 下載此專案並解壓縮。
2. 在 Chrome 開啟 `chrome://extensions`，開啟「開發人員模式」。
3. 點「載入未封裝項目」，選擇專案內的 `extension` 資料夾。
4. 登入 Threads，點擴充功能圖示開啟面板。

更新時，替換原資料夾內的檔案，在擴充功能頁按「重新載入」，再重新整理 Threads。

## 使用方式

1. 開啟目標內容的「查看動態 → 按讚」。
2. 在工具中選擇名單區域，確認橘框圈選正確，再開始收集。
3. 結束收集後檢查名單，勾選要處理的帳號與作者選項。
4. 勾選封鎖確認，再按「一鍵封鎖」。

首次會開一個工作分頁準備並校驗請求；成功後，其餘已選帳號在背景並行處理。保留工作分頁即可，不必逐人切換。並行上限依確認名單人數計算，實際網路速度由瀏覽器及 Threads 決定。

## 使用前要知道

- 只能收集網頁載入的帳號，不能保證包含所有按讚者。
- 封鎖會實際改變你的 Threads 帳號狀態。暫停或中止不會撤銷已完成的封鎖，已送出的請求仍可能完成。
- 網站可能限制請求或改變介面；結果不明不代表成功，也不會自動重試。
- 目前仍有服務端拒絕請求及恢復執行時沿用失敗範本的已知問題。遇到錯誤請中止並核對結果，避免反覆按繼續。
- 這不是 Meta 或 Threads 官方提供的工具。

## 資料與隱私

名單與操作紀錄保存在瀏覽器本機，工具沒有自己的遠端資料收集服務。封鎖請求會使用你已登入的 Threads 工作階段，請求範本暫存在頁面記憶體，不寫入匯出檔。

匯出的診斷會省略憑證，但仍可能包含帳號、數字 ID、來源連結及操作時間。請勿直接上傳到公開 issue 或公開儲存庫。

## 開發

使用 Node.js 22 以上，無需安裝第三方 npm 套件：

```sh
npm test
npm run test:browser
npm run test:profiles
```

瀏覽器測試使用獨立 Chrome 設定檔與本機模擬頁，不操作你的登入帳號。可透過 `CHROME_PATH` 指定 Chrome 執行檔。
